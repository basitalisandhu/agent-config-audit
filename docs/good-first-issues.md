# Good first issues

The current list lives on GitHub under the
[`good first issue` label](https://github.com/basitalisandhu/agent-config-audit/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22).
Each issue names the files to change and has acceptance criteria that `make check` can verify.

Before you start, read [CONTRIBUTING.md](../CONTRIBUTING.md): `ruff` must pass, rule ids are never
reused, every rule change needs a fixture and a test, `make docs` regenerates the rule tables in
`docs/checks.md`, and `make example` must be run when the committed sample report changes. Comment
on the issue to claim it; small pull requests are welcome.
